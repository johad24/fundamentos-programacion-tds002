# Lo que aprendí con esta asignación

1. A usar Git y GitHub de forma práctica: crear ramas, hacer commits
   descriptivos, y unir cambios con merge.

2. A estructurar un programa en métodos reutilizables en vez de escribir
   todo el código de corrido en Main.

3. A manejar listas, arreglos y estructuras de control para resolver
   problemas del mundo real, como un sistema de préstamos de biblioteca.
