# Sistema de Control de Préstamos de Biblioteca

## Descripción
Programa de consola en C# que permite gestionar el catálogo de libros de una
biblioteca: agregar libros, listarlos, prestarlos, devolverlos, buscarlos por
título, y eliminarlos del catálogo. Es el proyecto final de la asignatura
Fundamentos de Programación (TDS-002).

## Funcionalidades
1. **Agregar libro** — registra un nuevo libro con título y autor.
2. **Listar libros** — muestra todo el catálogo con su estado (disponible o prestado).
3. **Prestar libro** — marca un libro como prestado a una persona.
4. **Devolver libro** — marca un libro prestado como disponible de nuevo.
5. **Buscar libro** — busca por título (coincidencia parcial, sin distinguir mayúsculas).
6. **Eliminar libro** — elimina un libro del catálogo; si está prestado, pide una razón para darlo de baja.

## Tecnologías usadas
- C# (.NET 10)
- Estructuras: List<T>, condicionales, ciclos (do-while, for, foreach), métodos con parámetros y retorno.

## Cómo ejecutarlo
1. Clona el repositorio o descarga la carpeta 14-ProyectoFinal.
2. Abre una terminal dentro de la carpeta 14-ProyectoFinal.
3. Ejecuta el comando: dotnet run
4. Sigue el menú en pantalla escribiendo el número de la opción deseada.
